Read this before citing the numbers

  • MMLU is a 40-question subset. All Wilson 95% intervals overlap; point-estimate deltas are noise, not findings.
  • AWQ vs HF is the clean quantization comparison because both ran in the HF engine: 2,588 MiB vs 4,380 MiB, or 41% less VRAM. AWQ throughput was lower.
  • Published vLLM vs AWQ is confounded by engine and quantization together. configs/benchmark_v2.yaml is prepared with a same-engine vLLM+AWQ run.
  • vLLM memory includes preallocated KV cache. It is not a model-weight-only footprint.
  • Published run has one repeat per concurrency level. p95 variance is unknown; v2 uses 3 repeats and adds error bars.
